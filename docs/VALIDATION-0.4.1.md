# Validation 0.4.1 — 8 octobre 2026

La collecte de données est désormais **exclusivement manuelle** : le démarrage Electron n’appelle plus `refreshData`, y compris sur une base ancienne, au premier démarrage ou après une mise à jour du binaire. Le bouton Actualiser et la CLI explicite restent les points d’entrée. Les anciens paramètres `scrapingEnabled: true` indiquent les sources à inclure dans le clic et ne rétablissent pas l’automatisation.

Le catalogue Data Dragon du même patch est relu depuis le JSON local validé ; les PNG présents sont conservés. Le bouton vérifie le petit index de versions, puis télécharge le nouveau catalogue ou les fichiers manquants si nécessaire. Les feeds HTTPS gardent leur ETag et peuvent répondre 304. Un second clic fonctionne immédiatement, sans le délai de 30 minutes de l’ancien lancement automatique.

Lolalytics conserve les détails des anciens patchs déjà importés, complète les absents et revalide le patch actif. gol.gg vérifie les agrégats et le nombre de games par tournoi : les listes inchangées restent en cache, les séries modifiées sont recontrôlées pour trouver de nouvelles games. Les statistiques des matchs joués sont réutilisées. Le checkpoint précédent est sauvegardé avant la nouvelle requête ; les nouveaux compteurs ne remplacent ce checkpoint qu’après une collecte complète réussie. Une interruption reste donc reprenable. La fenêtre demeure trois patchs par source, Master+ pour Solo Queue.

L’écran Données explique l’actualisation manuelle, affiche la dernière réussite et garde un bouton explicite. Les chemins de données ne contiennent pas la version de l’application. SQLite, équipes, sessions et caches restent en place lors du changement de binaire ; NSIS conserve explicitement les données applicatives.

- **57 tests unitaires dans sept fichiers réussis**. Sept nouvelles régressions couvrent le catalogue et les icônes réutilisés, le nouveau patch, le feed conditionnel, les anciens détails Solo et les données manquantes, le cache brut expiré sans réseau, les matchs pro conservés, les nouvelles games d’une série modifiée et la reprise après interruption.
- **TypeScript et build Electron/React réussis**, puis packaging NSIS Windows x64.

Les **1 066 packs**, leurs dates d’import et tailles, la draft, les équipes, paramètres et sessions restent conservés. Deux clics réels sur le bouton, avec réponses Data Dragon simulées dans le main, ne demandent que deux index de versions ; aucun catalogue ou PNG n’est retéléchargé. Aucune erreur renderer. - **Test général sur le binaire final réussi** : draft manuelle, annulation, double pick, scénarios, sessions, pool, démo, FR/EN et overlay synchronisé. `contextIsolation` et sandbox vérifiés sur les deux fenêtres.
