# Focus — design 4 retenu

La [maquette Focus](04-focus.png) a été validée pour la version 0.8.0. Elle sert de référence visuelle : graphite/prune, lavande et menthe, navigation horizontale, équipes à gauche, décision au centre, contexte à droite.

L'application utilise les vrais champions, portraits Data Dragon, scores et données du moteur. Les textes et chiffres de cette image générée sont illustratifs. La disposition conserve les filtres, la saisie manuelle, les deux imports OP.GG, les sessions, les doubles picks, le Fearless et l'overlay. Les vues compactes permettent le défilement de chaque colonne et de la liste centrale.

Les trois autres propositions restent des explorations locales ; seule la référence retenue est suivie dans le dépôt.
